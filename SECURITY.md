# Security

Report vulnerabilities through the repository's
[private security advisory form](https://github.com/Ismail-elkorchi/http-client/security/advisories/new).
Include the affected version, a minimal reproduction, and the expected impact.

Public network access is enabled by default. Requests to local, private,
special-purpose, and mixed public/non-public address sets are rejected unless
the client is explicitly configured to allow them.
